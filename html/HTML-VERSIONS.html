HTML 1.0 (1991)

The first version of HTML, HTML 1.0, was invented by Tim Berners-Lee in 1991 andreleased in 1993

﻿ HTML 1.0 was a basic markup language that introduced a set of tags for structuring digital documents. The original version included 18 tags, element tags for paragraphs and forheadings.

HTML 2.0 (1995)

HTML 2.0 Was introduced in 1995, The first standarized version laying the groundwor on the web development

HTML 3.2 (1997)

HTML 3.2 was published at January 14, 1997 as a W3C recommendation, was first developed for W3C, had aditions like tables, applets and text flow around images.

HTML 4.0 (1997)

HTML 4.0, a major update to the HTML specification, was published as a W3C Recommendation in December 1997 and revised in April 1998, had many browser specific element types and attributes but also a netscape's visual markup features.

HTML 4.01 (1999)

On December 24, 1999 HTML 4.01 was published, it offers the same three varitions as HTML 4.0 and its last errata were poblished on may 12, 2001

XHTML 1.0 (2000)

XHTML 1.0 is a reformulation of HTML 4.01 as an Extensible Markup Language (XML) 1.0 application. Published as a World Wide Web Consortium (W3C) recommendation on January 26, 2000, it enforced stricter syntax rules than its predecessor, HTML. XHTML 1.0 was an effort to bridge HTML and XML, providing developers with a version of HTML that could be viewed and edited with standard XML tools.

HTML5 (2014)

The first working draft of HTML 5 was published in January 2008. Adoption of HTML 5 was gradual between 2008 and 2012, and then steady. HTML 5 was finally issued as a W3C Recommendation in 2014, HTML5 introduced a wide range of new features for multimedia, performance, and structure, eliminating the need for many external plugins like Adobe Flash.
